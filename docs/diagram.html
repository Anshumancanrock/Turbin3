pre-req-vault

A per-wallet SOL vault. withdraw also registers the caller with the registration program through a CPI.

InstructionWhat it doesState afterWho signs the move
initialize Creates vault_state, saves both bumps vault_state exists, vault empty no transfer
deposit Moves SOL from user into the vault vault holds the SOL the user
withdraw Moves SOL back out, then registers the user application_account created, once only the vault PDA
close Drains the vault, closes vault_state, refunds rent both accounts gone the vault PDA

The vault holds no key of its own. Both PDAs are derived from seeds containing the user's public key, so only that user's vault can ever be derived, and the program authorises a withdrawal by passing those seeds instead of a signature.
